Notes de sprint

Un éditeur portable et hors-ligne, pensé pour la lecture.

  • Aucune télémétrie
  • Aucun installeur
  • 100 % natif Windows

Conçu sans compromis

Chaque contrainte du projet est tenue au même niveau d'exigence, du premier lancement à la dernière ligne de code.

  • 100 % portable — un dossier, aucun installeur, jamais.
  • 100 % hors-ligne — aucune requête réseau, aucune télémétrie.
  • Rendu natif — FlowDocument WPF, sans moteur HTML embarqué.
  • Thème clair / sombre — automatique, ou basculé en un clic.
  • Interface bilingue — Français / Anglais, détectée au démarrage.
  • Licence libre — GNU GPL-3.0-or-later, code source ouvert.

Trois façons de travailler

Le même document, sous trois angles — basculez en un raccourci clavier.

Lecture

Un rendu Markdown/GFM complet — titres, tableaux, citations, listes de tâches — dans une mise en page aérée et lisible.

Ctrl 1

Édition

Texte brut avec coloration syntaxique dédiée au Markdown, pour écrire vite sans quitter le clavier.

Ctrl 2

Vue partagée

Source et rendu côte à côte, synchronisés, pour relire pendant que vous écrivez.

Ctrl 3

Clair le jour, sombre le soir.

Le thème suit celui de Windows par défaut, ou se bascule manuellement — l'interface et le rendu du document changent ensemble.

Clair

Papier clair, encre foncée. Confortable en plein jour.

Sombre

Fond profond, texte doux. Pensé pour les longues sessions du soir.

Mise en route

Aucune installation, aucun compte, aucune attente.

  1. 1

    Téléchargez

    Récupérez le dossier MarkDownEditor depuis les releases GitHub et placez-le où vous voulez, y compris sur une clé USB.

  2. 2

    Lancez

    Double-cliquez sur MarkDownEditor.exe. Aucune dépendance .NET à installer au préalable.

  3. 3

    Ouvrez un fichier

    Utilisez Ouvrir, ou associez l'extension .md pour ouvrir vos fichiers en un double-clic.
